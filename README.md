# Simple Expense Tracker

This is a basic command-line application to track your expenses. You can:

- Add new expense entries with date, category, amount, and description.
- View all recorded expenses.
- See the total expenses for a specific category.
- Delete an expense by its entry number.
- Exit the program.

## How to Run

1.  Make sure you have Python installed on your system.
2.  Save the code as a Python file (e.g., `expense_tracker.py`).
3.  Open your terminal or command prompt.
4.  Navigate to the directory where you saved the file.
5.  Run the command: `python expense_tracker.py`

## Usage

Follow the on-screen menu to interact with the expense tracker. Enter the corresponding number for the action you want to perform.
